## 2. 직접 해 보는 법

### 준비

1. 최신 코드 받기: `git pull` (브랜치 `feature/rig-characters-vfx`)
2. 프로젝트 폴더에서 `python serve.py` → 브라우저로 <http://localhost:8099/> 열기
3. 높은 스테이지를 바로 열려면 메인 화면 **왼쪽 위 아이콘을 5번 연속**(각 1초 안) 누름. 모든 스테이지가 이번 실행 동안만 열림.
4. 휴대폰 앱(NAS 0.2.4 빌드 10)에는 **아직 이 수정이 없습니다**. 새 빌드 전까지는 PC 브라우저로 확인해 주세요.

### 1. 1-1 졸개 무적

| 단계 | 할 일 |
|---|---|
| 준비 | 아래 셋 중 하나로 1-1 출격 (강화 없이) |
| | 거대괴수: 다리 **점액질 기동 포자**(포자 패시브) |
| | 합성괴인: 기본 파츠 그대로 (다리 **지진 분쇄 다리** = 진동 패시브) |
| | 타락 히어로: 몸통 **흑마법 룬 갑옷** (저주 패시브) |
| 확인 | 1~2분 진행하면서, 주인공 앞 적이 맞는데도 안 쓰러지는 경우가 없는지. 쓰러진 적은 넘어지며 사라져야 함 |
| 예전 모습 | 초반에 적 한 마리가 계속 서서 공격하고, 주인공 공격이 그 적에게 안 들어감 |

### 2-1. 소환수가 떨어져 싸울 때 주인공 이동

| 단계 | 할 일 |
|---|---|
| 준비 | 합성괴인 기본 파츠(몸통 **강화 생체 코어** = 졸개 소환)로 1-1 출격 |
| 확인 | 졸개가 앞으로 나가 적과 붙으면 주인공도 **그 자리까지 걸어가서** 같이 싸우는지. 그동안 위쪽 진행 거리(m)가 거의 안 늘어야 함 |
| 예전 모습 | 졸개가 멀리서 싸우는데 주인공은 제자리에서 걷는 동작만 하고 거리만 늘어남 |

### 2-2. 거점을 지나친 소환수

| 단계 | 할 일 |
|---|---|
| 준비 | 2-1과 같음. 졸개가 적을 쫓아 화면 오른쪽 멀리 나간 상태에서 중간 요새가 나타나는 순간을 봐야 해서, 손으로는 잘 안 만들어짐 |
| 확인 | 요새가 나타났을 때 졸개가 요새보다 오른쪽에 있어도 **요새를 공격**하는지 (요새 체력 막대가 줄어듦) |
| 예전 모습 | 요새를 그냥 두고 서 있거나 계속 오른쪽으로 감 |
| 참고 | 자동 검사 `test_qa_fixes`가 이 상황을 직접 만들어 확인함 (아래 3장) |

### 3. 거대로봇 팔 카드 그림

| 단계 | 할 일 |
|---|---|
| 준비 | 캐릭터 선택에서 거대로봇 → 연구소 → **팔** 탭 |
| 확인 | **장거리 저격포 · 플라즈마 방사 팔 · 쌍열 가속포** 카드에 대포 팔 그림이 보이는지 |
| 예전 모습 | 세 카드의 그림 칸이 비어 있음 |

### 4. 적이 땅에서 뜨는 문제

| 적 | 나오는 스테이지 | 확인 |
|---|---|---|
| 처형인 성기사 | 3-8 원수의 얼굴 · 3-9 · 3-10 | 걸을 때 발이 돌길에 닿는지 (엘리트도) |
| 이단심문관 | 3-3 피 묻은 채찍 · 3-4 · 3-5 · 3-6 | 같음 |
| 처형의 군의관 | 6-8 해부학의 달인 · 6-9 · 6-10 | 같음 |
| 블라디미르 (보스) | 8-B 심장이 얼어붙는 온도 | 같음 (예전엔 약 43px 떠 있었음) |
| 파노프티콘 (보스) | 9-B 설계 변경 | 같음 |

- 비교 기준: 옆에 있는 다른 적(광신도 등)의 발과 같은 높이면 정상.
- 공격할 때 대검 끝이 땅 아래로 들어가는 부분은 잘려 보일 수 있습니다(땅속이라 일부러 자름).

## 4. 알아 둘 점

- **소환 캐릭터 진행 속도**: 아군이 싸우는 동안 주인공이 그 자리로 걸어가고 거리가 안 쌓이므로, 합성괴인·거대괴수(산란)·타락 히어로(세뇌)·봉합 성녀·인형사가 예전보다 조금 늦게 진행될 수 있습니다. 밸런스를 다시 잴 때 참고해 주세요.
- **적 그림 굽기 규칙이 바뀜**: 앞으로 `tools/rig/bake_enemies.py`로 적을 구우면, 땅 아래로 내려가는 그림은 자동으로 잘립니다. 하늘에 떠 있는 적(걷기 발이 땅 위)은 예전과 같습니다.
- **원인이 된 줄**: 협력 모드의 '체력 0 이하 적은 무시' 줄(`enemyField.js` `dealDamageToEnemy` 첫 줄)은 그대로 두었습니다. 같은 프레임에 두 번 처리되는 것을 막는 줄이라 필요합니다. 체력을 직접 깎는 코드를 새로 만들 때는 `defeatEnemy()`를 불러 주세요.
